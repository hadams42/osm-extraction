Key Capabilities

Unified View Toggle

Seamlessly switch between the familiar grid/list view and the new map view. All filters remain synchronized—search by division, status, or project type and see results update in real-time on both views.

Smart Clustering

With thousands of projects, intelligent clustering groups nearby markers to prevent visual overload. Zoom in to explore individual projects or zoom out to see regional patterns.

Rich Project Popups

Click any project marker to see essential details: project name, division, current status, workflow year, and priority flags—with a direct link to open the full project record.

Contextual Data Layers

Overlay mission-relevant data including population density, unreached people group concentrations, the 10/40 Window, and SDA organizational boundaries.

🔒 Security-First Design

Projects marked as sensitive locations are automatically excluded from the map view, protecting the precise coordinates of mission work in restricted regions while maintaining full functionality in the traditional list view.

Exploration Layers

The map will support multiple toggleable data layers to provide context for strategic decision-making:

Mission Intelligence

  • SDA Division & Union Boundaries
  • 10/40 Window Highlight Zone
  • Unreached People Group Density
  • Religious/Worldview Distribution

Demographics

  • Population Density Heatmap
  • UN Urban Agglomerations
  • GDP per Capita by Country
  • Language Family Regions

Infrastructure

  • Accessibility Index (travel time)
  • Major Road Networks
  • Airports and Transportation Hubs
  • Administrative Boundaries

Contextual Factors

  • Religious Persecution Index
  • Natural Hazard Risk Zones
  • Project Density Heatmap
  • Funding Distribution Overlay

Expected Benefits

  • Enhanced Strategic Planning: Leadership can visualize global reach and identify expansion opportunities through geographic analysis
  • Improved Resource Allocation: See where funding and projects are concentrated versus underserved areas with high need
  • Faster Decision Making: Visual patterns reveal insights that would take hours to compile from tabular data
  • Better Stakeholder Communication: Compelling visual presentations for board meetings, donor reports, and strategic sessions
  • Integrated Workflow: Same filters, same data, new perspective—no learning curve for existing users

Technical Foundation

This enhancement builds on existing infrastructure already in place within the Mission Priority System:

  • ArcGIS Integration: The system already uses ArcGIS JavaScript API for existing map widgets
  • SDA Feature Layers: Adventist.earth ArcGIS server with division boundaries is already configured
  • Geographic Database: Existing geo schema with urban areas, coordinates, and spatial data
  • People Group Data: Joshua Project integration already provides unreached people demographics
  • Location Tracking: Projects already capture latitude, longitude, and urban area references
